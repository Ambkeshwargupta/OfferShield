# Contributing

1. Fork the repository and create a branch for your change.
2. Keep source attribution and uncertainty visible in company profiles.
3. Never add guessed registration numbers, employee names, phone numbers or recruitment policies.
4. Never describe a company or person as fraudulent solely because information was not found.
5. Do not scrape LinkedIn, bypass CAPTCHAs or circumvent a site's access controls.
6. Run `npm run check` and `npm test` before opening a pull request.
7. Do not commit API keys, personal data, offer letters or production user information.

For company profile changes, include the source URL, source type, access date and the exact claim supported by that source.
